# Расширение для сайта Nekto.me на базе Chromium

Расширение, которое добавляет красивую панель справа в голосовую чат-рулетку Nekto.me.

## Функционал

**Разговор**
- Авто-скип собеседника и кнопка «Скипнуть сейчас»
- Пинг до собеседника во время звонка
- Выключение микрофона с первой секунды разговора (без ожидания минуты)
- Звук телепорта, когда скипаешь ты и когда скипают тебя
- Мини-окно «картинка в картинке» поверх всех программ: таймер, индикатор голоса собеседника, громкость, авто-скип, скип, стоп и микрофон

**Звук**
- Выбор микрофона и наушников прямо в панели
- Самопрослушка своего микрофона и индикатор уровня

**Оформление**
- Приглушённые ночные темы: Graphite, Mica, Ocean, Forest, Lavender, Amber, Aurora, Crimson
- Плавная смена тем и плавные анимации переходов
- Анимированные фоны: звёзды, созвездия, светлячки, туманность, дождь, снег, ночной город, луна
- Готовые обои или своя картинка на фоне, затемнение и размытие
- Прозрачность окна чата, яркость и плотность фона, параллакс
- Часы вверху страницы, компактная панель
- Скрытие рекламы

**Статистика**
- Разговоров всего и за сегодня
- Общее и среднее время, самый длинный разговор
- Скипы и поиски

**Прочее**
- Самопроверка: если сайт обновится и что-то перестанет работать, панель предупредит
- Сброс всех настроек к значениям по умолчанию

# Установка

1. Скачиваете весь проект (Code → Download ZIP)
2. Из архива переносите все файлы в отдельную папку
3. Заходите по ссылке — `chrome://extensions/`
4. На этой странице есть переключатель «Режим разработчика» — его нужно включить
5. Нажимаете «Загрузить распакованное расширение»
6. Выбираете папку с расширением
7. Открываете или обновляете вкладку https://nekto.me/audiochat

После обновления расширения обновите и вкладку с сайтом.

## Свой звук скипа

По умолчанию играет встроенный синтезированный звук «телепорта».
Чтобы поставить свой, положите файл в папку `sounds/` с именем `ender.mp3`
(или `skipped.ogg` / `skipped.mp3` / `skipped.wav`) и перезагрузите расширение.
